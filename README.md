p.22 本章のPoint: 「cos x (0 ≤ x)」は上限の π が抜けています(正しくは 0 ≤ x ≤ π)。p.10 の本文と図 0.1 は 0 ≤ x ≤ π です。
p.22 オイラーの公式: 「|e^{iθ}| = cos²θ + sin²θ = 1」は √ が抜けています(正しくは √(cos²θ + sin²θ) = 1)。

p.10, p.22: tan x の定義域が −π/2 ≤ x ≤ π/2 と閉区間で書かれていますが、
±π/2 では tan が定義されません。
正しくは −π/2 < x < π/2 です。

p.37 (1.12):g_n(x) を「最初の n 項」と言っていますが、Σₖ₌₀ⁿ は n+1 項です。
h_n(k=1〜n)は n 項で合っています。「最初の n+1 項」か、和を k=0〜n−1 にするかのどちらかが必要です

p.67 1.6:f₀(x)=eˣ を閉区間 −π≤x≤π で与えると、f₀(−π)=e⁻π と f₀(π)=e^π が食い違い、周期的に並べた関数が定義できません。
Exercise 1.7 のように −π≤x<π が適切です。

p.66 1.2:ロピタルの定理として (イ)=f′(a)/g′(a) になるには g′(a)≠0 が必要ですが、書かれていません。
